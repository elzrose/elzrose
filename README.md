## 🕷️ PROJECTS FROM MY WORKSHOP

### 🔴 01. KAIYOPPU

**Trust Every Hire**

A platform designed to establish trust between informal workers and people looking to hire them.

Kaiyoppu aims to make informal employment more transparent, accessible and trustworthy.

**Key Features**
- Separate Worker, Hirer and Admin roles.
- Government verification workflow.
- QR-based worker identity.
- Selfie verification and cryptographic photo-lock concept.
- A trust-focused platform connecting workers and hirers.

**Tech Stack**

`React` `Vite` `Firebase` `JavaScript`

### 🔵 02. CUNEIFORM

**A Universal Complaint Management System**

<a href="https://arnedev-cuneiform.netlify.app/">
  <img src="https://img.shields.io/badge/LIVE%20DEMO-OPEN-EF3038?style=for-the-badge"/>
</a>
<a href="https://github.com/NavaneethNem/Cuneiform">
  <img src="https://img.shields.io/badge/SOURCE%20CODE-GITHUB-1677D2?style=for-the-badge"/>
</a>

**24 hours. That's all we had.**

Built by **Team ARNE DEV** during Code Kalari, a national-level 24-hour hackathon organized by IIIT Kottayam.

Cuneiform bridges the gap between students and administration through a transparent, real-time complaint management system.

**Key Features**
- 🤖 **AI-powered analysis:** Detects urgency and sentiment to help prioritize complaints.
- 🗳️ **Community voting:** Students can upvote pressing issues to bring them to administrators' attention.
- 👻 **Anonymous reporting:** Encourages honest feedback without revealing identities.
- 🔒 **Evidence locker:** Supports photo and video attachments as complaint evidence.
- 🔐 **Private mode:** Allows sensitive complaints to be visible only to administrators.

**Tech Stack**

`HTML5` `CSS3` `JavaScript ES6+` `Custom DataService`

### 🔴 03. VOXSCRIBE

**Full-Stack AI Speech-to-Text Engine**

VoxScribe is a speech-to-text web application that converts voice recordings and uploaded audio files into accurate text transcriptions using the **Deepgram Nova-2 AI engine**.

Built with a vibrant neo-brutalist design system featuring yellow, black and white, it combines real-time recording, audio uploads and secure cloud-synchronized transcript storage.

**Key Features**
- 🎙️ **Live recording:** Capture audio directly through the browser microphone using the MediaRecorder API.
- 📁 **Audio uploads:** Upload audio files for transcription.
- 🧠 **AI transcription:** Uses Deepgram Nova-2 to convert speech into punctuated text.
- 🔐 **Authentication:** User login and signup through Supabase Auth.
- ☁️ **Transcript vault:** Store and retrieve previous transcriptions from the database.
- 🎨 **Neo-brutalist UI:** High-contrast visuals with an animated soundwave equalizer.

**Tech Stack**

`React` `Vite` `Tailwind CSS` `Node.js` `Express.js` `MongoDB Atlas` `Mongoose` `Deepgram Nova-2` `Supabase Auth`
