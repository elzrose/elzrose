### Kaiyoppu — Trust Every Hire

A platform designed to build trust between **informal workers and people looking to hire them**.

- Worker, Hirer and Admin roles.
- Government verification workflow.
- QR-based worker identity.
- Selfie verification and cryptographic photo-lock concept.
- Designed to make informal work more transparent and trustworthy.

**Tech:** React • Vite • Firebase • JavaScript
